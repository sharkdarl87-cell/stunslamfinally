# Stun Slam (Fabric, Minecraft 26.2)

Voll-automatischer Stun Slam. Du musst nicht selbst schlagen.

- G: an/aus
- H: Modus wechseln (Smart / Immer Combo)

Hotbar: Axt und Mace.
Du springst von oben auf einen Gegner und zielst auf ihn. Die Mod zieht die Mace selbst,
schlaegt bei Schild erst mit der Axt und dann mit der Mace (Smash).
